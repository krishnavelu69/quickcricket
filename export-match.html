QuickCricket — Export Saved Data

This helper reads saved QuickCricket data from this browser address only. It does not change or delete your match.

Important: Open this page at http://localhost:8002/export-match.html while your original QuickCricket server on port 8002 is running.

It will export the saved match and any QuickCricket Supabase connection settings found in this browser origin into one JSON file.
